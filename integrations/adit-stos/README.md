# NAIB Public Front · ADIT / ADIT-STOS Boundary

This public repository does not connect directly to STOS authority and does not embed protected NOEMA runtime code.

The public role is intentionally narrow:

```text
visitor
  |
  v
NAIB.github.io
canonical public Administrator identity
  |
  | governed request / proposal
  v
NOEMA protected administrative intelligence runtime
  |
  v
ADIT / ADIT-STOS
cognition, continuity, provenance, capability mediation
  |
  v
STOSCore
specialist-family routing
  |
  v
STOS trust spine
consequential authority
```

## Rules

- NAIB may explain, organize, coordinate, research, prepare and propose.
- Public presentation is not proof of execution.
- No public file may contain credentials, protected STOS configuration, administrative secrets or private-core source.
- ADIT proposals do not become authority at this layer.
- The public front must not connect directly to the normal STOS Gateway or bypass ADIT-STOS / STOS policy.
- Human authority remains final.

The protected runtime contract is maintained separately in `artist1970/noema-ai.github.io`.
