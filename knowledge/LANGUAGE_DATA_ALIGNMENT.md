# NAIB Language Data Alignment — v1

## Existing workspace
The browser-local Code Capsule already exists at `artist1970/creative-spark.github.io/NAIB-language-data.html`. Do not recreate, rename, overwrite its localStorage, or expose its contents through the public website.

## Authority model
NOEMA is the protected, non-public Chancellor. NAIB is the public ecosystem navigator, administrator, delegator, and second in command. The public chat presents guidance and coordination proposals only. Delegation, authorization, privileged memory, and execution must remain behind the governed boundary. A proposal is not an executed action.

## Public synchronization scope
- Public page: `index.html`
- Read-only public guidance: `knowledge/public-guidance.v1.json`
- Public conversation adapter: `naib-public-conversation-v1.js`
- Local workspace: Creative Spark `NAIB-language-data.html` (separate origin and local storage)

## Required bridge
Only explicitly selected, approved-public records may be exported from the local Code Capsule. A review process must check schema, stable IDs, provenance, duplicate records, secrets, privileged instructions, and source rights. Publication requires a human-reviewed versioned commit and rollback receipt. No automatic live syncing of administrative records or private state. Public chat must never ingest NOEMA operational data.
